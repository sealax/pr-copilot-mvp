# Codex Working Rules

Before any work:

- Create the specified branch
- Do not work directly on main
- Do not merge automatically
- Only complete tasks assigned to the current branch
- Preserve:
  - Supabase auth
  - OpenAI routes
  - Usage tracking
  - Existing database schema

When complete:

- Run build checks
- Commit changes
- Summarise:
  - Files changed
  - Components added
  - Potential issues
- Wait for review

Never start the next branch without approval.
